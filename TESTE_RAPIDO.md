# Teste rápido — versão 0.1

1. Instale as dependências e execute `streamlit run app.py`.
2. Carregue cada CSV da pasta `samples`.
3. Confira a classificação dos campos, os vazios, duplicidades e a prévia.
4. Se possível, teste também um Excel com mais de uma aba.

Critérios de aceite:
- [ ] Aplicação abre sem erro.
- [ ] Os quatro CSVs são carregados.
- [ ] Todas as colunas aparecem no perfil.
- [ ] Valores vazios e duplicidades são contabilizados.
- [ ] Colunas de data plausíveis são identificadas.
- [ ] Perfil pode ser exportado em CSV.

Registre classificações incorretas para ajustarmos as regras.
