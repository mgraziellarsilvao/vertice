# Prompt para ChatGPT — desenvolvimento

Atue como engenheiro de dados e desenvolvedor Python sênior. Estou construindo o Automated Insights Generator em Python, Pandas e Streamlit. A aplicação deve receber arquivos CSV/Excel de diferentes áreas, sem exigir um modelo fixo.

Nesta versão, o escopo é carregar arquivos, identificar tipos de coluna, apresentar perfil, valores ausentes, valores distintos e exemplos.

Regras: não invente colunas nem assuma domínio; preserve compatibilidade com bases variadas; explique alterações por arquivo; inclua testes e casos-limite; não trate inferência heurística como certeza; não misture alertas de privacidade com score de qualidade. Examine o código atual antes de propor alterações e não presuma que a versão local é igual a versões anteriores.
